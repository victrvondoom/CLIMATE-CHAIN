## Cross-cutting platform features

- API-fed source views for waste, fire, water and air, with `LIVE`/`SIMULATED` labels.
- Place-based Waste-to-Air review with provenance and non-causal interpretation boundaries.
- Five-stage mission guidance and capability selection across all 13 folders.
- Local engineering-memory capture, explicit human review, agent-rule export, encrypted Windows vault and stdio MCP retrieval.
- Durable local gateway missions with validated DAGs, deterministic allowlisted tasks, evidence and report export; the separate five-stage browser simulation remains available and labeled.
- Keyboard command palette for navigation and capability discovery.

No common account, shared source database, universal transaction bus or cross-project impact total is implied by these features.
