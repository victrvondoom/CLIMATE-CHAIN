# Known limitations

## Product scope

- Climate Chain remains a command center plus adapters, not a unified backend for all 13 projects.
- No central account, role authorization, persistence, case state machine, approval record or intervention outcome store exists.
- Cascade Review is a read-only evidence lead for public DumpWatch sites and AirPulse monitor responses. It cannot confirm environmental harm, identify a cause, create municipal work, or verify a cleanup.
- AshAlert, TapAlert and AirPulse overview adapters still have schema/privacy work before they are safe for generalized central storage.
- Projects outside the four civic adapters are not API-connected. Capability cards and external links are navigation, not integration.

## Data and evidence

- Public API reachability and source mode are different from independently verified field conditions. Live source badges only describe successful upstream transport.
- AshAlert stats can include demo/seed composition. TapAlert remains a global snapshot, though the central view only receives aggregate counts. AirPulse's Today contract does not expose exact monitor coordinates.
- Cascade defaults are review filters, not scientific or regulatory thresholds. A match is a proximity lead, not evidence of causality.
- Manifest hashes are not signed, time-stamped by an independent authority, persisted append-only or anchored externally.
- The 3D globe is schematic and its overview arcs are decorative. It is not terrain, a satellite basemap or a verified causal network.

## Operations and security

- No live endpoint, deployment, notification, payment or contract transaction was exercised.
- Previously committed/copied Pinata credentials may remain valid; an authorized operator must revoke and rotate them with Pinata, then configure the replacement server-side.
- Several specialist projects have no root license or unresolved data terms. They remain isolated until reuse rights are clear.
- Project README test counts and deployment claims were not independently reproduced. Specialist test suites remain to be run; the SupplyTrail standalone lint script needs noninteractive ESLint configuration.
- The frontend build warns about the separately loaded Three.js chunk, roughly 553 kB minified.
